# CertiK Security Assessment

The KCG token contract was assessed by **CertiK** (final report **2025-12-01**; formal verification, manual review, static analysis). Result: **no Critical / Major / Medium / Minor findings**; 2 centralization and 2 informational notes, acknowledged and addressed through the governance and multisig controls described in [`../security/`](../security/).

The full report is **not published** under its distribution terms. The complete public mapping — scope, deployed-contract alignment with BscScan, findings summary and mitigations — is maintained on the official docs site:
