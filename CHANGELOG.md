# Changelog

All notable public-facing changes. Dates are UTC.

## 2026-10 — Dalgona, Android app, public docs

- **Dalgona** launched at `dalgona.koreaculturegame.com` and in the lobby: 3D candy carving with server-side judging, 14 shapes across six difficulty tiers, speed bonus, best-time records. Judge published as `packages/dalgona-judge`.
- **KCG Android app** (`kcg.koreaculturegame`) entered Google Play internal testing: Google sign-in, all games in one app, shared Cash wallet (purchases coming), English UI.
- **Privacy policy** and **terms of service** published at koreaculturegame.com.
- Platform: stale-asset handling fixed across all game servers (old bundles now 404 instead of returning HTML), immutable caching for hashed assets, service-worker kill switch for legacy installs.

## 2025-12 — Token

- CertiK security assessment of the KCG token (final report 2025-12-01): no critical/major/medium/minor findings.
- KCG (BEP-20) deployed on BNB Smart Chain: `0x1a5093B6f1ef2fc4f45Cb651cb2fb9Ce14eb79A5`, fixed supply 500B.
- Public GitBook with tokenomics, address registry, governance and multisig disclosures.

## 2025 — Games

- Red Light Green Light (single + 456-player live battle), Tug of War, Younghee, Glass Bridge (3D), Spinning Top (idle mining), Rock Paper Scissors event — launched as web games on `*.koreaculturegame.com`.
